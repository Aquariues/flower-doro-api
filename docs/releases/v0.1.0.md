# v0.1.0

First FlowerDoro API release.

## Highlights

- Go + Gin API backed by PostgreSQL.
- Dockerfile plus development and production Docker Compose setup.
- GoAdmin management UI at `/admin`.
- Versioned database migration with the 100-flower FlowerDoro catalog.
- User garden, flower book, timer settings, and focus-session reward APIs.
- Server-side 30-minute minimum for flower rewards.

## Verification

- `go test ./...`
- Docker dev stack build and health check
- Flower catalog seed count: 100
- 29-minute focus completion creates no reward
- 30-minute focus completion creates a random flower reward
